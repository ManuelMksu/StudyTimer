# Study Session Timer

A simple command-line Python application to track study sessions with a countdown timer and logging.

## Features
- Start a timed study session with a subject.
- Visual progress bar during countdown.
- Logs sessions to a text file.
- View past study logs.

## Usage
1. Run the script: `python study_timer.py`
2. Choose option 1 to start a session.
3. Enter duration in minutes and subject.
4. Wait for the timer or press Ctrl+C to stop early.
5. Choose option 2 to view logs.
6. Choose option 3 to exit.

## Requirements
- Python 3.x
